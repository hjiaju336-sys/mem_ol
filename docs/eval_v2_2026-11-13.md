> 数据：本地 `斗破苍穹.txt` 前 60000 字（仅本地，不进入仓库）。
> 本次变更：关系改为自由 `relation_label`，删除 `relation_type` / `evidence`；旧数据已清空。
> 新线程：`斗破·60k 评测-v2`。

## 0. 先说明导入质量

本次导入触发了一次 **403 免费额度耗尽**：

```text
world.consolidate.failed
Error code: 403 - Free quota exhausted
```

结果：

- 向量化 / 分块成功：806 chunks（父 111 / 子 695）；
- 实体 48、关系 64；
- **整理 agent 失败，走 exact-canonical 兜底**，`degraded=true`；
- 因此实体去重不完整，例如：
  - `黑色戒指` / `黑色古朴戒指` / `母亲遗物` 重叠；
  - `成*人仪式` / `成年仪式` 重叠。

所以：

- **上下文召回指标可信**（与实体整理无关）；
- **实体/关系数量偏多，实体去重指标暂不可信**；
- 关系标签本身已经能反映自由语义，例如：
  - `药老 -[收为徒弟]-> 萧炎`
  - `萧炎 -[指腹为婚的未婚夫(已单方面休弃)]-> 纳兰嫣然`
  - `纳兰嫣然 -[当事人(提出方)]-> 退婚事件`
  - `洗骨花 -[炼制原料]-> 筑基灵液`

### 每一路都有独立贡献的样例

**上下文路不可少：**

- “萧炎的未婚妻是谁？”：上下文 rank 1，实体路 rank 7。

**实体路不可少：**

- “药老住在什么地方？”：上下文未命中，实体 rank 1。
- “筑基灵液需要哪些材料？”：上下文未命中，实体 rank 1。
- “薰儿小姐是谁？”：上下文未命中，实体 rank 1。
- “后山指的是哪里？”：上下文未命中，实体 rank 1。
- “绿色魔晶是什么？”：上下文未命中，实体 rank 1。

**结论：**

- 上下文路负责原文细节和关系句；
- 实体路负责别名、专名和实体中心问题；
- 单路都覆盖不全，双路融合后 @5 = 1.0；
- 关键词和向量在本批题上仍然高度重合，未能证明二者互为必需；
- 精排只改善 top1/MRR，不改善 Recall@5。

## 3. 关系 / 事件实体

自由标签关系探针 7 条：

| 关系 | 标签命中 |
|---|---|
| 药老 → 萧炎 | 收为徒弟 |
| 药老 → 黑色古朴戒指 | 寄居 |
| 纳兰嫣然 → 云岚宗 | 亲传弟子 |

| 萧战 → 萧炎 | 父子 |
| 洗骨花 → 筑基灵液 | 炼制原料 |
| 纳兰嫣然 → 退婚事件 | 当事人（提出方） |

结果：`7/7` 命中。

说明：

- 自由 `relation_label` 能表达师徒、父子、寄居、材料、退婚等语义；
- “退婚事件”作为 event 实体存在，关系落在实体上，不需要把“退婚”塞进关系枚举；
- 同一对实体可以有多条不同标签的关系边。

## 5. 结论

- 自由关系标签 + 事件实体化方向可用，且已经产生比旧枚举更具体的关系；
- 上下文路和实体路都有独立贡献，融合必要性成立；
- 精排有排序收益，但不负责召回；
- 关键词 vs 向量仍未被区分，需要更硬的别名/描述题；
- 导入整理因 403 降级，实体去重数据暂不干净，正式指标需额度恢复后重跑；
- 回退和长程召回仍然稳定；
- 拒答阈值、歧义澄清、世界时钟仍是明确边界。
